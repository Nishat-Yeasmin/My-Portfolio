# 🌐 Nishat Yeasmin - Portfolio

A modern and responsive personal portfolio website built with **Next.js** and **Tailwind CSS**. This portfolio showcases my projects, technical skills, educational background, and journey as a Computer Science & Engineering student and aspiring Software Engineer.

## 🔗 Live Demo

**Portfolio:** https://my-portfolio-indol-alpha-uczfljwvm9.vercel.app

---

## ✨ Features

* Responsive design for all devices
* Modern and clean user interface
* Smooth animations and transitions
* Detailed About Me section
* Skills showcase
* Projects section with dedicated project details pages
* Contact section
* Fast performance with Next.js App Router

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Nishat-Yeasmin/My-Portfolio.git
```

### Navigate to the project

```bash
cd https://github.com/Nishat-Yeasmin/My-Portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
